# Пример решения

Каталог показывает форму и в работе не используется. Заводя своё решение, скопируйте его целиком и перепишите этот файл.

## Задача

Разбирается кейс занятия [00-example](../../../../workshops/00-example/README.md). Скажите своими словами, что требовалось спроектировать.

## Решение

Опишите схему и объясните, почему выбраны эти компоненты. Отдельно назовите место, которое упрётся первым при росте нагрузки.

## Доска

Экспортируйте доску через «Export image» с включённым «Embed scene», сохраните её рядом с этим файлом под именем `board.excalidraw.svg` и вставьте сюда строку.

```text
![Схема заказа](./board.excalidraw.svg)
```
