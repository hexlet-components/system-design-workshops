# Библиотека компонентов Excalidraw

Набор готовых компонентов для быстрого проектирования и прототипирования архитектуры. Позволяет не начинать работу с пустого листа.

Файл `component-library.excalidraw.svg` представляет собой экспортированное SVG-изображение с встроенной исходной сценой Excalidraw (**Embed scene**), поэтому он одновременно отображается как картинка и доступен для полноценного редактирования.

---

## Как импортировать файл в Excalidraw

Есть два простых способа открыть файл для работы:

1. **Перетаскивание:**
   - Откройте сайт [excalidraw.com](https://excalidraw.com/).
   - Перетащите файл `component-library.excalidraw.svg` прямо в окно браузера.

2. **Через меню «Открыть»:**
   - Перейдите на [excalidraw.com](https://excalidraw.com/).
   - Нажмите на иконку меню в левом верхнем углу (гамбургер-меню ☰).
   - Выберите **Open** (Открыть) и укажите файл `component-library.excalidraw.svg`.

---

## Совместная работа (Шаринг доски)

Чтобы работать над доской вместе с другими пользователями в реальном времени:

1. Откройте нужную доску в Excalidraw.
2. В правом верхнем углу нажмите желтую/синюю кнопку **Share** (Поделиться).
3. В появившемся окне нажмите **Start session** (Начать сессию).
4. Нажмите **Copy link** (Копировать ссылку) и отправьте её коллегам или студентам.
5. Любой пользователь, перешедший по ссылке, подключится к вашей доске в браузере с поддержкой синхронизации изменений в реальном времени.

---

## Сохранение изменений

При экспортe обновлённой доски всегда используйте следующие параметры:
* **Формат:** `Export image` -> **SVG**.
* **Опция:** обязательно включите галочку **Embed scene** (Встроить сцену).
* **Имя файла:** заканчивайтся на `.excalidraw.svg`.
